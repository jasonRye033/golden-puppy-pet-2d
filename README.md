# 金毛小狗桌宠 — 2D 精绘平涂卡通版 (`golden-puppy-pet-2d`)

这是基于 Electron + Canvas 2D Retina (2x) + `uiohook-napi` 打造的**独立 2D 精绘平涂卡通版**金毛小狗桌面宠物，支持 **macOS (Apple Silicon & Intel)** 与 **Windows**。

> 原 3D 皮克斯版已完整保留在 `../golden-puppy-pet` 目录中，两个版本互不干扰。

---

## 核心特性

1. **小狗第一人称视角键鼠 (180° 朝向小狗)**
   - **60% 紧凑机械键盘**：空格行 (`Space`, `Cmd`, `Opt`, `Fn`) 紧贴小狗肚皮一侧，数字行 (`1–0`, `ESC`, `⌫`) 朝向屏幕最底端（离小狗最远），键帽印字以小狗第一人称朝向排布，按压时亮起清脆绿光 (`#73E831`)、键帽下沉并伴随 1.1 秒余晖与头顶弹出键帽气泡。
   - **第一人称无线鼠标**：位于画面左侧半透明防滑鼠标垫上（小狗的**右手**控制），鼠标左/右键分界线与橙色滚轮朝向下方（小狗手指前端），随全局鼠标移动在垫上平滑滑动，左/右键点击亮绿光，滚轮滚动触发绿色波纹。
2. **自然身体跟随伸展 + 短粗圆润肉垫小爪**
   - 当小狗伸右手握鼠标或伸手去按远端按键（如左下角退格、右下角 `ESC`）时，**躯干、肩膀与头部会自然向目标方向滑移与倾侧**，让手臂始终保持短粗圆润的 Q 版比例，绝不拉成僵硬细长的“橡皮面条手”。
   - 胸前奶油色蓬松胸毛 (`chest_bib.png`) 与头部自然覆盖肩部连接处，无任何接缝痕迹。
3. **高精度 2D 赛璐璐手绘分层 + 眼睛视线实时跟随鼠标光标**
   - 采用粗深棕圆润勾线 (`#2E1C10`)、暖金黄与奶油白平涂色块分层渲染。
   - **视线实时追踪**：小狗的双眼黑棕色虹膜、瞳孔与双高光点在眼眶遮罩 (`eye_mask_*.png`) 内实时平滑追踪屏幕上的鼠标光标位置，并在打字时自动聚焦到正在敲击的键帽上，带自然眨眼动画。
   - **多状态表情切换 & 摸头撸狗互动**：
     - 平时微笑注视光标、高频打字（>3 keys/sec）开心吐舌头 + 高频摇尾巴、30 秒无操作自动趴在键盘上打呼噜冒泡 (`Zzz`)。
     - **摸头互动**：鼠标移到小狗头顶/耳朵区域来回移动（揉搓 2~3 下）即可触发撸狗反应——**享受眯眼 + 吐舌头开心笑 + 头部顺着鼠标揉搓方向歪斜蹭手 + 疯狂摇尾巴**（普通单向路过或按住左键拖拽窗口不会误触）。
4. **5 档自由缩放 & 隐私安全 & 纯透明防遮挡背景**
   - **右键「窗口大小」5 档缩放**：支持 **50%（迷你） / 75%（小巧） / 100%（标准） / 125%（大号） / 150%（特大）** 一键切换，以窗口**右下角**为锚点等比缩放（全程动态 Retina 矢量级重绘，放大 150% 依然清晰锐利），并自动记住上次的缩放档位与屏幕位置。
   - 窗口除小狗、键盘与半透明鼠标垫外 **100% 纯透明**，绝不遮挡桌面视线。
   - 按键事件仅在内存中实时驱动动画，**绝不记录、落盘或上传任何按键内容**。
   - 右键菜单支持一键 **「隐藏字母」**（仅保留爪子敲击与键帽亮灯，不弹出字母气泡）与 **「退出」**。

## 快速运行 (开发模式)

```bash
cd /Users/dashitou/.gemini/antigravity/scratch/golden-puppy-pet-2d
npm start
```

内置自动演示模式（无需动手，自动循环演示握鼠标滑动/点击/滚轮、远端按键身体自然伸展、双手高频打字吐舌头、打瞌睡）：

```bash
npm run demo
```

## 打包安装包

- **打包 macOS (`.dmg`)**：
  ```bash
  npm run dist:mac
  ```
  生成文件位于 `dist/金毛桌宠2D-1.0.0-arm64.dmg` (Apple Silicon) 和 `dist/金毛桌宠2D-1.0.0.dmg` (Intel)。

- **打包 Windows (`.exe`)**：
  ```bash
  npm run dist:win
  ```

## macOS 权限说明

由于需要全局监听键盘与鼠标动作以驱动小狗同步敲击，首次在 macOS 运行时请在 **系统设置 → 隐私与安全性** 中为终端（开发模式）或 `金毛桌宠2D.app`（安装包模式）开启：
- **辅助功能 (Accessibility)**
- **输入监控 (Input Monitoring)**
